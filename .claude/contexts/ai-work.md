## Best Practices

1. **Start simple** - Basic prompt → add complexity only when needed
2. **Measure first** - Establish baseline before optimizing
3. **Version prompts** - Treat prompts as code, track changes
4. **Test with real data** - Synthetic data hides edge cases
5. **Monitor costs** - Token usage adds up quickly
